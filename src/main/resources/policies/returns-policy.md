## Standard return window

Most items may be returned within **30 days of the delivery date**. The window is
measured from the date the carrier marks the parcel delivered, not the order date
and not the shipment date. Orders that have not yet been delivered cannot be
returned; if the parcel is still in transit, wait for delivery or refuse it at the
door, which routes it back to the warehouse automatically.

Items in the FURNITURE category carry an extended **60-day** window because of
assembly time. Everything else follows the standard 30 days.

## Condition requirements

Returned items must be in resalable condition: unused or lightly tested, with all
original accessories, manuals, and packaging. Items showing cosmetic damage,
missing parts, or removed serial labels are subject to a partial refund at the
inspection team's discretion.

Opened AUDIO products (headphones, earbuds, speakers) are accepted for hygiene
reasons only when the sealed inner wrapper is intact, or when the return reason is
a manufacturing defect.

## Non-returnable items

The following are final sale and cannot be returned under any circumstances:

- Digital gift cards and store credit (category `GIFT_CARD`)
- Downloadable software licences once the activation key has been revealed
- Perishable goods and consumables (category `PERISHABLE`)
- Made-to-order and personalised items

If an order contains a mix of returnable and non-returnable items, the returnable
lines can still be returned individually; the non-returnable lines are excluded
from the return and from any refund calculated for it.

## How to start a return

A return is opened by requesting a Return Merchandise Authorisation (RMA). Each
approved request produces an RMA number in the form `RMA-` followed by eight
characters, plus a prepaid label emailed to the address on the order. Pack the
item, attach the label, and drop it with the carrier within **14 days** of the RMA
being issued or the authorisation lapses and a new request is required.

Only one open RMA may exist per order line at a time.

## Return shipping costs

Return shipping is free when the return reason is a defect, a damaged parcel, or a
fulfilment error on our side. For change-of-mind returns a flat **$6.95** label fee
is deducted from the refund. Furniture returns over 20 kg incur the actual carrier
freight cost, quoted before the RMA is confirmed.

## Exchanges

Direct exchanges are not processed. Return the original item for a refund and place
a new order; this avoids holding stock against an unreceived return, and the new
order ships immediately rather than waiting for the inbound parcel.
